4wlls

terminal style capcut subtitle extractor

overview

4wlls is a specialized web application designed to extract dialogue from capcut project files and convert them into srt subtitles. the interface utilizes a terminal aesthetic inspired by low level programming environments.

features

seamless capcut json to srt conversion

ai powered dialogue refinement using gemini

interactive draggable preview interface

full responsiveness for desktop and mobile devices including s25 ultra

real time system logging and terminal output

copy to clipboard and direct srt download options

workflow

locate your capcut draft folder and find the draft_content.json file.

upload or drag the file into the interface.

initiate the conversion sequence.

use the ai refinement tool to polish grammar and natural flow.

download the srt or copy the output for use in video editors.

technology

vanilla javascript logic

tailwind css styling

gemini flash api for linguistic processing

responsive design for high end mobile displays
